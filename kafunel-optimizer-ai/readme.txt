Advanced image optimization plugin with AI integration for WordPress. Optimize images using local methods (GD/ImageMagick) and external AI APIs.

== Description ==

Kafunel Optimizer AI is a powerful WordPress plugin that helps you optimize your images for better website performance. Using both local optimization techniques and AI-powered external services, you can significantly reduce your image file sizes while maintaining quality.

= Key Features: =
* Supports JPEG, PNG, GIF, and WebP input formats
* Outputs to JPEG, PNG, WebP, and AVIF formats
* Multiple compression levels: Lossless, Optimal, Lossy, Maximum
* Automatic resizing with customizable dimensions
* Intelligent conversion to WebP/AVIF formats
* Integration with the WordPress media library
* Bulk optimization capabilities
* API integration for advanced AI processing
* Daily usage limits for free version
* Pro version with unlimited optimizations and advanced features

= Free vs Pro: =
* Free: Up to 10 optimizations per day, 20 images per batch
* Pro: Unlimited optimizations, AI background removal, upscale, video optimization, detailed reports

== Installation ==

1. Upload the `kafunel-optimizer-ai` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings > Kafunel Optimizer AI to configure your preferences
4. Enter your API key if using external services (optional)
5. Start optimizing your images!

== Frequently Asked Questions ==

= What image formats are supported? =
We support JPEG, PNG, GIF, and WebP as input formats. Output formats include JPEG, PNG, WebP, and AVIF.

= Is there a limit to how many images I can optimize? =
The free version allows up to 10 optimizations per day. The Pro version provides unlimited optimizations.

= Does this work with other plugins? =
Yes, Kafunel Optimizer AI is designed to work alongside other WordPress plugins without conflicts.

= Can I use this without an API key? =
Yes, our local optimization features work without an API key using GD or ImageMagick libraries.
